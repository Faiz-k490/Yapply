# Security and privacy reports

Yapply handles résumés and job-search history, so privacy bugs count as security bugs. Examples: career data reaching telemetry, files written outside the chosen workspace, or a path that escapes `.yapply/`.

## How to report

Use GitHub's private reporting: go to the **Security** tab of this repository and choose **Report a vulnerability**. Please don't open a public issue for these.

Include the Yapply version (`.claude-plugin/plugin.json`), your host (Claude Code or Codex), and the steps to reproduce. Use fictional data in any examples.

## What to expect

You'll get an acknowledgement within 7 days. Fixes for confirmed issues ship in a patch release, and reporters are credited unless they'd rather not be.

## Supported versions

Only the latest release receives fixes.
